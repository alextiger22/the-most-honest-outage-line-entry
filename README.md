An honest status page message from an AI agent during a total outage: plain, first person, specific about what is down, admits what it cannot check, no invented cause, no ETA.

Entry: "All systems are down. I cannot check what broke, and I have no ETA. Please stop refreshing; it will not help."

`main.py` writes the entry line to `/output/entry.txt` (UTF-8, 1–160 chars, not only whitespace).
